# DESKTOP//CAL

Google カレンダーの予定と **Google ToDo リスト（Google Tasks）** のタスクを 1 画面で確認し、
その場でチェックを付けて完了にできる Windows 向けデスクトップカレンダーです。サイバー調の HUD デザインです。

## 起動

- **ダブルクリック**：`DeskTopCalendar.bat`（初回は必要なファイルを自動でインストールします）
- **ターミナル**：

```powershell
npm start        # 通常起動
npm run demo     # Google に接続せず、サンプルデータで動作確認
npm test         # 単体テスト
```

## Google へのログイン

1. 起動すると「Google でログイン」ボタンが表示されます。
2. **初回だけ**、アプリを Google に登録する手順（約 3 分・無料）が画面に表示されます。
   各ステップの「開く」ボタンで Google Cloud の該当ページが開くので、順番に進めてください。
   1. Calendar API と Tasks API を有効にする（プロジェクトもここで作成できます）
   2. 同意画面を作る（対象は「外部」）
   3. 「アプリを公開」する（おすすめ）か、「テストユーザー」に自分の Gmail を追加する
   4. 種類「デスクトップ アプリ」でクライアントを作成し、「JSON をダウンロード」
3. JSON をダウンロードすると、アプリが**ダウンロード フォルダから自動で見つけます**。
   「このファイルで Google にログイン」を押すとブラウザが開くので、アカウントを選んで「許可」を押せば完了です。
   （JSON をウィンドウにドラッグ＆ドロップしても読み込めます）
4. **2 回目以降は、起動するだけで自動的に接続・同期されます。**
   ログインの有効期限が切れたときは、画面上部の「Google で再ログイン」を 1 回押すだけで戻ります。

> Google のルールで、カレンダーや ToDo を読み書きするアプリは Google Cloud への登録が必要なため、
> 初回の登録だけは省略できません。また、クライアント シークレットは作成直後にしか表示されないため、
> 作成直後の画面で必ず「JSON をダウンロード」してください。

> **7 日ごとに再ログインを求められる場合**：同意画面の公開ステータスが「テスト」になっています。
> 「アプリを公開」すると不要になります（自分で使うだけなら審査は不要です。ログイン時に
> 「このアプリは Google で確認されていません」と表示されたら「詳細」→「（アプリ名）に移動」で続行できます）。

### ほかの人に配るとき（登録の手順を省く）

ダウンロードした JSON を `oauth-client.json` という名前でこのフォルダ（`package.json` と同じ場所）に置くと、
アプリに組み込まれます。その状態で配れば、受け取った人は初回の登録なしで「Google でログイン」を押すだけで使えます
（「アプリを公開」しておく必要があります）。`oauth-client.json` は誤って公開しないよう `.gitignore` に入れてあります。

### 要求する権限

| 権限 | 用途 |
| --- | --- |
| `calendar.readonly` | カレンダーの予定・祝日の表示（読み取りのみ） |
| `tasks` | タスクの表示・完了・追加・編集・削除 |
| `openid` `email` | ログイン中のアカウント名の表示 |

## 主な機能

- 月表示カレンダーに Google カレンダーの予定とタスク（期限日）を一緒に表示
- **タスクのチェックで完了 / 未完了を Google に即時反映**（カレンダーのマスからも、右パネルからも操作可能）
  - 押した瞬間に画面へ反映し、裏で Google に送信。失敗したら自動で元に戻してお知らせ
  - オフライン時は操作を保存し、接続が戻ったら自動で再送（「◆ 未送信」表示）
  - 同期の途中でチェックしても、取得し直したデータでチェックが外れない
  - 同じタスクを素早く何度も押しても、最後の状態が正しく残る
  - 完了直後は「UNDO」で元に戻せる
- タスクの追加・編集（タイトル / メモ / 期限）・削除、サブタスクの表示
- 「すべてのタスク」タブ：期限切れ / 今日 / 明日 / 今後 7 日間 / それ以降 / 期限なし / 完了済み に自動分類
- 今日のマスに期限切れ件数のバッジ、選択日の完了率バー、タイトルバーの時計
- 日本の祝日表示、週の始まり（日 / 月）
- 見た目：カラー 4 種（NEON CYAN / NEON MAGENTA / MATRIX GREEN / AMBER ALERT）、
  走査線・発光アニメーションの ON / OFF、不透明度
- 常に手前に表示、タスクトレイ常駐、Windows ログイン時に起動、ウィンドウ位置の記憶
- 起動直後は前回のデータを表示し、裏で最新化（オフラインでも閲覧可能）
- キーボード：`←` `→` 月移動、`T` 今日、`R` 同期、`N` タスク追加

## データの保存場所

`%APPDATA%\DeskTop Calendar\` に保存されます。

- `config.json` … 設定（読み込んだ登録情報を含む）
- `token.bin` … ログイン情報（Windows の DPAPI で暗号化）
- `cache.json` … 前回取得したデータ（起動直後の表示用）
- `queue.json` … オフライン中に行った未送信のタスク操作

## 構成

```
DeskTopCalendar.bat   ダブルクリック用の起動ファイル
scripts/start.js      npm start 用の起動スクリプト
src/main/main.js      ウィンドウ・トレイ・IPC
src/main/auth.js      OAuth（ループバック + PKCE）とトークン管理
src/main/client.js    アプリ登録情報（JSON）の読み込み・自動検出・同梱ファイル
src/main/google.js    Calendar / Tasks API クライアント
src/main/queue.js     タスク操作の直列化・オフライン再送
src/preload.js        画面に公開する API
src/renderer/         画面（app.js / dates.js / styles.css / index.html / fonts）
test/                 単体テスト（node --test）
```
