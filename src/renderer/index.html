INITIAL SETUP

アプリを Google に登録する（最初の 1 回だけ）

Google のルールで、カレンダーや ToDo を読み書きするアプリは Google Cloud への登録が必要です（無料・約 3 分）。登録が済めば、あとは「Google でログイン」を押すだけで自動的につながります。

  1. API を有効にするプロジェクトを作成（または選択）して、2 つの API をそれぞれ「有効にする」
  2. 同意画面を作る「開始（Get started）」→ アプリ名と自分のメールを入力 → 対象は「外部（External）」→「作成」
  3. 使う人を設定「アプリを公開（Publish app）」がおすすめです（7 日ごとの再ログインが不要になります）。テストのままにする場合は「テストユーザー」に自分の Gmail を追加
  4. クライアントを作成して JSON を保存「クライアントを作成（Create client）」→ 種類「デスクトップ アプリ（Desktop app）」→「作成」→ 表示された画面で「JSON をダウンロード」
ダウンロード フォルダを監視中… JSON を保存すると自動で見つけます
